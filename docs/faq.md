# Вопросы и неполадки

**Нода в панели «не на связи» после установки.**
Панель должна достучаться до порта 3000 ноды. `ss -ltn | grep 3000` на ноде — слушает?
Если ставили с `--panel-ip`, проверьте, что IP панели указан верно (`ufw status`). Хостеры
иногда закрывают порты своим файрволом — смотрите панель хостера.

**В логах ноды ошибка TLS-рукопожатия с панелью (SSL alert 40 и похожее).**
Нода новее панели. Обновите панель или пиньте версию ноды:
`sudo ./install-node.sh --force --secret … --image ghcr.io/remnawave/node:2.8.0`
(версию возьмите из панели). `--force` сохранит старые файлы рядом.

**Где взять SECRET_KEY?**
Панель → Nodes → карточка ноды. Одна строка на все ноды.

**`geodata: … НЕ СКАЧАЛСЯ`.**
С этого сервера не открывается GitHub (бывает у российских хостеров). Скачайте четыре файла
на любой другой машине и положите в `/var/lib/remnanode/` (`scp`), затем запустите снова —
скрипт увидит файлы и не будет качать.

**Debian 12: скрипт написал «docker compose v2 в apt нет — ставлю docker из репозитория Docker».**
В Debian 12 в apt только старый docker-compose (v1). Скрипт сам ставит docker из официального
репозитория Docker (get.docker.com) — это штатный способ, ничего делать не нужно.

**Нужен ли `--bridge` для выходной ноды?**
Нет. Geodata нужна там, где есть правила маршрутизации по спискам — на мосту.

**`tune-resilience.sh` что-то перезагрузит?**
Нет. Watchdog и panic-ребут срабатывают только когда ядро или systemd уже зависли.
Единственное, что нужно сделать руками после него, — `docker restart remnanode`, чтобы
xray взял новую очередь приёма; можно ночью.

**`health.sh` показывает `retr=n/a`.**
Трафика за 5 секунд слишком мало, процент ретрансмитов не имеет смысла. На нагруженной
ноде норма — до 1%; 2–3% и выше — потери на линке.

**`probe-speed.sh` показывает 0 Мбит/с.**
Источник замера недоступен с сервера (часто — зарубежный с российского моста). Задайте
свой: `SRC_EU=https://… SRC_RU=http://… ./probe-speed.sh` — любой файл от 1 ГБ по GET.

**`probe-steal.sh` показывает 20–40%.**
Гипервизор отдаёт вашей виртуалке не всё время CPU — хостер перепродал сервер. Видео и
игры через такой мост «рвутся» при нормальной полосе. Лечится сменой тарифа или хостера.

**Как откатить всё?**
По каждому скрипту — [SAFETY.md](SAFETY.md): у `tune-*.sh` есть `--undo`, у `install-node.sh`
бэкапы `*.bak-<дата>`, у `geodata-update.sh` — `*.bak` и автооткат.
